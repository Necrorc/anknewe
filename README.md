# Картотека — карточки для языка (PWA для iPhone)

Веб-приложение на HTML/CSS/JS, которое устанавливается на iPhone как обычное
приложение (иконка на экране) и работает **полностью офлайн** после первой
установки. Все данные (колоды, карточки, прогресс повторения) хранятся прямо
на телефоне, в IndexedDB — никакого сервера, никакого Telegram, ничего не
нужно держать включённым.

Функциональность такая же, как у телеграм-бота, плюс кое-что новое: колоды
(независимые группы карточек), добавление вручную, импорт CSV/JSON,
интервальное повторение (SM-2 lite), выбор направления (слово→перевод /
перевод→слово / вперемешку), повтор карточек в сессии, пока не ответишь
верно на все, статистика — и **режим «Слушать»**, который читает все карточки
колоды вслух подряд (слово, потом перевод), чтобы можно было учить язык на
слух, не глядя в экран.

## Режим «Слушать»

Вкладка «🔊 Слушать» читает вслух все карточки активной колоды по очереди —
слово на изучаемом языке, пауза, перевод, пауза, следующая карточка — так
можно слушать колоду как подкаст, не держа телефон в руках. Работает через
встроенный в iOS синтезатор речи (Web Speech API) — так же полностью офлайн,
без интернета.

Управление: пауза/воспроизведение, вперёд/назад по карточкам, переключатели
«случайный порядок» и «повторять по кругу» (бесконечный луп для фоновой
прокрутки).

**Важно про язык произношения**: у каждой колоды теперь есть язык слов и
язык перевода (задаются при создании колоды или потом через ✏️ на строке
колоды в списке колод) — иначе, например, польское слово прочиталось бы с
русским произношением. По умолчанию для новых колод — польский → русский,
это легко поменять на нужную пару (английский, немецкий, французский,
испанский, итальянский, украинский, русский).

## Прямо во время «Учить»

Карточку можно переворачивать сколько угодно раз подряд — тап снова показывает
слово, ещё один тап снова показывает ответ, и так далее. Удобно, если после
ответа хочется ещё раз взглянуть на слово. Кнопки «Знал» / «Не знал» появляются
после первого переворота и остаются доступны, даже если потом вернуться
к лицевой стороне — отвечать можно в любой момент, не обязательно с открытым
ответом на экране.

На карточке есть ещё две мелкие кнопки:

- **🔊** (правый верхний угол карточки) — озвучивает вслух ту сторону
  карточки, что сейчас видна (слово до переворота, перевод после), голосом
  нужного языка. Не переворачивает карточку.
- **🗑** (рядом со строкой «осталось выучить: N») — удаляет текущую карточку
  из колоды навсегда, с подтверждением. Полезно, если попалось опечатанное
  или ненужное слово прямо во время повторения — не нужно идти на вкладку
  «Карточки» отдельно.

## Как считается интервал повторения

Внутри одной сессии карточка, на которую ответили «Не знал», возвращается
в конец очереди и показывается снова — так что сессия заканчивается только
когда все карточки отвечены верно хотя бы раз. Но на долгосрочный интервал
повторения (когда карточка появится в следующий раз, через день / 3 дня /
неделю и т.д.) влияет только **первая попытка** по каждой карточке за
сессию:

- Угадали с первого раза → уровень карточки растёт, следующий показ
  откладывается дальше.
- Ошиблись на первой попытке (даже если через пару кругов всё-таки
  вспомнили) → уровень сбрасывается на 1 (частый повтор, но не самое начало) — итоговый
  правильный ответ в рамках той же сессии на это уже не влияет.

Это отличает по-настоящему выученные с первого раза слова от тех, что
дались с трудом, даже если в конце сессии оба варианта помечены «знал».

Если хочешь пройти всю колоду заново (например, после долгого перерыва) —
на вкладке «Карточки» кнопка «Сбросить уровни» позволяет вручную сбросить
уровень всех карточек колоды до 1 или до 0 и сразу сделать их доступными
к повторению. Карточки при этом не удаляются — сбрасывается только прогресс.

## Редактирование карточек

В списке карточек рядом с ✕ (удалить) есть ✏️ — открывает то же поле
«слово / перевод», что и при добавлении, только уже заполненное текущими
значениями. Если исправленная пара совпадёт с какой-то другой карточкой
в той же колоде, сохранение отклонится как дубль (карточка не поменяется).

Так же ✏️ появляется и в режиме «Учить» — рядом с 🗑, но только в момент,
когда виден ответ (после переворота карточки). Правка применяется сразу,
без перезапуска сессии.

## Экспорт колоды

На вкладке «Карточки» кнопка «Экспорт» скачивает все карточки активной
колоды файлом `.csv` или `.json` (на выбор) — ровно в том же формате, что
понимает «Импорт файла», так что файл можно тут же загрузить обратно (себе
или на другое устройство) без потерь. Имя файла берётся из названия колоды.

## Объединение колод

На экране «Колоды» кнопка «🔗 Объединить колоды» открывает выбор двух колод:
всё содержимое первой переедет во вторую (дубли — одинаковые пары
слово+перевод — пропускаются, как и везде в приложении), а первая колода
удалится. Работает только для колод с одинаковой языковой парой (слово и
перевод) — иначе объединение заблокировано, чтобы не перемешать разные
языки в одной колоде.

## Настройки

Вкладка «⚙️ Настройки» (последняя в меню снизу):

- **Подтверждать удаление карточки** — если выключить, кнопка 🗑 в режиме
  «Учить» удаляет карточку сразу, без всплывающего вопроса «Уверен?».
  (Подтверждение при удалении из списка «Карточки» и при очистке/удалении
  колод целиком остаётся всегда — это переключает только быстрое удаление
  прямо во время повторения.)
- **Кнопка удаления карточки в «Учить»** — сверху рядом со счётчиком
  «осталось выучить» (по умолчанию) или снизу, под кнопками «Знал» / «Не
  знал».

Настройки хранятся на устройстве и не сбрасываются при перезапуске
приложения.

## Почему нельзя просто "включить .py на айфоне"

iOS не даёт запускать сторонние исполняемые файлы (в т.ч. Python) в обход
App Store — это ограничение самой платформы, не наше. Реальные варианты были:
Pythonista/Pyto (покупка приложения-интерпретатора), нативная сборка через
BeeWare/Kivy (нужен Mac + Xcode + Apple ID), или веб-приложение (PWA). Ты
выбрал(а) PWA — оно не на Python (HTML/CSS/JS), зато не требует ничего,
кроме однократной публикации файлов и Safari.

## Важно: нужен один раз статический хостинг

PWA нельзя "просто открыть" двойным щелчком и получить офлайн-режим и кнопку
"На экран Домой" — Safari требует, чтобы страница была отдана по `https://`
(или `http://localhost`), иначе Service Worker (то, что обеспечивает офлайн-
работу) не активируется. Это **не сервер в смысле бота** — файлы статические,
ничего не считается на бэкенде, но разместить их где-то по https нужно.
Самый простой бесплатный вариант — **GitHub Pages**:

### Шаг 1. Выложить файлы на GitHub Pages

1. Создай новый репозиторий на [github.com](https://github.com) (можно приватный).
2. Загрузи в него все файлы из этой папки (`index.html`, `style.css`, `db.js`,
   `app.js`, `manifest.webmanifest`, `service-worker.js`, папку `icons/`) —
   через веб-интерфейс (Add file → Upload files) или `git push`.
3. В репозитории: **Settings → Pages → Source: Deploy from branch → main /
   (root)** → Save.
4. Через минуту-две GitHub покажет ссылку вида
   `https://<твой-логин>.github.io/<репозиторий>/` — открой её в Safari
   **на iPhone**, чтобы проверить, что всё загрузилось.

(Вместо GitHub Pages подойдёт любой другой статический хостинг — Netlify,
Cloudflare Pages, Vercel — процесс аналогичный: загрузить папку, получить
https-ссылку.)

### Шаг 2. Установить на домашний экран

1. Открой полученную ссылку в **Safari** на iPhone (обязательно Safari, не
   Chrome — только Safari умеет ставить PWA на домашний экран на iOS).
2. Нажми кнопку "Поделиться" (квадрат со стрелкой вверх) внизу экрана.
3. Выбери **"На экран «Домой»"**.
4. Нажми "Добавить".

Готово — на экране появится иконка "Картотека". Она открывается как обычное
приложение (без адресной строки Safari) и с этого момента работает офлайн:
можно выключить Wi-Fi/интернет совсем, приложение продолжит работать, а все
карточки и прогресс сохраняются на телефоне.

### Про обновления

Если ты попросишь что-то доработать и я пришлю новые файлы — обнови их в том
же репозитории (замени файлы, GitHub Pages подхватит автоматически). При
следующем открытии приложения на телефоне Service Worker скачает новую
версию файлов в фоне (сами данные — колоды и карточки — при этом не
удаляются, они отдельно в IndexedDB).

## Структура файлов

```
index.html               — разметка всех экранов
style.css                 — оформление (тёмная тема, латунный акцент)
db.js                     — вся работа с IndexedDB (колоды, карточки, SRS)
speech.js                 — озвучка карточек через Web Speech API
app.js                    — логика интерфейса, импорт CSV/JSON, сессии обучения и прослушивания
manifest.webmanifest      — метаданные для установки на домашний экран
service-worker.js         — кэш для офлайн-работы
icons/                    — иконки приложения разных размеров
```

### Про обновления

Если ты попросишь что-то доработать и я пришлю новые файлы — обнови их в том
же репозитории (замени файлы, GitHub Pages подхватит автоматически). При
следующем открытии приложения на телефоне Service Worker скачает новую
версию файлов в фоне (сами данные — колоды и карточки — при этом не
удаляются, они отдельно в IndexedDB). Уже созданные колоды без языка
(из версии приложения без режима «Слушать») автоматически получат польский
→ русский по умолчанию — поменять можно через ✏️ на строке колоды.

## Импорт существующих карточек

Открой приложение → вкладка "Карточки" → "Импорт файла" → выбери `.csv` или
`.json`. Форматы те же, что понимал телеграм-бот — можно использовать файлы
`polish_b1.csv`, `english_b1_c2_all.json` и другие, которые уже были
сгенерированы ранее в этом разговоре.
