# Картотека — карточки для языка (PWA для iPhone)

Веб-приложение на HTML/CSS/JS, которое устанавливается на iPhone как обычное
приложение (иконка на экране) и работает **полностью офлайн** после первой
установки. Все данные (колоды, карточки, прогресс повторения) хранятся прямо
на телефоне, в IndexedDB — никакого сервера, никакого Telegram, ничего не
нужно держать включённым.

Функциональность такая же, как у телеграм-бота, плюс кое-что новое: колоды
(независимые группы карточек), добавление вручную, импорт CSV/JSON,
интервальное повторение (SM-2 lite), выбор направления (слово→перевод /
перевод→слово / вперемешку), повтор карточек в сессии, пока не ответишь
верно на все, статистика — и **режим «Слушать»**, который читает все карточки
колоды вслух подряд (слово, потом перевод), чтобы можно было учить язык на
слух, не глядя в экран.

## Мотивация: дневная цель, серия дней, напоминания

- **Дневная цель** (по умолчанию 20 карточек) настраивается на вкладке «Ещё».
  Учитываются ответы во всех колодах вместе — на экранах «Колоды» и «Учить»
  видно текущий прогресс («5 / 20 на сегодня»).
- **Серия дней подряд** (🔥) растёт каждый день, когда дневная цель выполнена,
  и сбрасывается, если пропустить день. Видна на экране «Колоды».
- **Напоминание** в заданное время («Пора повторить N карточек») — через
  Notification API. Полноценный push без сервера на телефон технически
  невозможен (особенно на iOS): напоминание сработает, только пока приложение
  открыто хотя бы в фоновой вкладке — это честное ограничение платформы, не
  недоработка. Разрешение на уведомления запрашивается отдельной кнопкой на
  вкладке «Ещё».
- **Прогноз повторений** (сегодня / завтра / на неделе / в течение месяца /
  позже) — на вкладке «Ещё», по датам следующего повторения карточек колоды.

## Расширенная статистика

На вкладке «Ещё», под обычной статистикой колоды:

- **Retention** — доля правильных ответов за последние 7 и 30 дней. Считается
  честно, по первой попытке ответа за сессию (как и интервал повторения) —
  подробнее см. раздел про интервалы ниже.
- **Тепловая карта активности** за последние 90 дней — сетка ячеек, чем темнее
  (ближе к акцентному цвету), тем больше ответов в этот день.
- **Распределение по уровням** — сколько карточек колоды на каждом уровне
  (0–5) интервального повторения.

## Теги и фильтры

- У каждой карточки можно указать **теги** через запятую (поле в модалке
  добавления/редактирования) — например, «еда, глаголы». Теги показываются
  под карточкой в списке.
- На экране «Учить» можно выбрать **«Только тег: X»**, чтобы повторять не всю
  колоду, а конкретную тематическую подборку.
- **«Учить всё»** — переключатель на экране «Учить» (виден, только если есть
  другие колоды с той же языковой парой) собирает карточки к повторению сразу
  из нескольких колод в одну сессию.

## Совмещение похожих карточек (омонимы и синонимы)

Кнопка **«Совместить похожие»** (вкладка «Карточки» → «⋯») находит в колоде:

- карточки с **одинаковым словом, но разными переводами** — например,
  «bank» → «берег» и «bank» → «банк» — и сводит их в одну карточку, где
  перевод становится нумерованным списком: `1. берег` / `2. банк`;
- карточки с **одинаковым переводом, но разными словами** — например,
  «shore» → «побережье» и «coast» → «побережье» — аналогично, но
  нумерованным становится уже слово.

Точные дубли (совпадает и слово, и перевод) эта кнопка не трогает — для них
есть отдельная «Убрать дубли». Действие можно отменить через тост сразу
после — восстанавливается всё как было.

Это же происходит **автоматически**, без отдельного нажатия:

- при обычном импорте CSV/JSON (если файл принёс уже известное слово с новым
  переводом или наоборот — они сразу сведутся в одну карточку);
- при объединении двух колод в одну.

## Перенос колод между устройствами (без сервера)

Три способа, в модалке «Экспорт» (вкладка «Карточки» → «⋯» → «Экспорт»):

- **.csv / .json** — как раньше, только слово и перевод (без прогресса).
- **📦 Полный бэкап (.kdeck.json)** — сохраняет ещё и прогресс (уровень, дату
  следующего повторения) и теги. Загрузи такой файл через «Импорт файла» на
  другом устройстве — определится автоматически, прогресс не потеряется.
- **🔗 Поделиться ссылкой** — колода (слова, переводы, теги — без прогресса)
  сжимается и кодируется прямо в адрес страницы, ничего не отправляется на
  сервер. При открытии такой ссылки приложение предложит импортировать колоду
  в отдельную новую колоду. Слишком большие колоды (ссылка вышла бы длиннее
  ~1800 символов) — приложение честно предупредит и предложит воспользоваться
  файлом вместо ссылки.

На экране «Колоды» есть ещё **«📦 Экспортировать всё»** — сохраняет сразу все
колоды (с прогрессом, тегами) в один файл `.kdeck.json`. Загрузи его через
«Импорт файла» на новом устройстве, чтобы перенести всё за один шаг — каждая
колода из файла создастся заново, не перезаписывая то, что уже есть.

## Отмена необратимых действий

Удаление колоды и очистка колоды (все карточки разом) — как и удаление
отдельной карточки — теперь тоже можно отменить через тост с кнопкой
«Отменить», который показывается сразу после действия. Восстанавливается
всё: сами карточки, их уровень повторения, даты следующего показа, теги
и даже цвет колоды.

## Визуальный дизайн

Интерфейс полностью переработан в духе современных PWA-тренажёров (Anki,
Notion, Duolingo) — чистый минимализм, спокойный индиго-акцент, скругления
12–16px, мягкие тени вместо жёстких границ.

- **Тёмная тема** по умолчанию переключается автоматически по системным
  настройкам устройства (`prefers-color-scheme`) — вечером глазам комфортнее,
  ничего вручную настраивать не нужно. Но если хочется зафиксировать
  конкретную тему навсегда (например, всегда тёмную, независимо от того,
  что выбрано в системе) — на вкладке «Ещё» → «Тема оформления» есть выбор
  «Как в системе» / «Светлая» / «Тёмная». Выбор сохраняется на устройстве.
- **Настоящий 3D-переворот карточки** в «Учить» — при клике карточка
  физически разворачивается в пространстве (не просто исчезает/появляется
  текст), декоративные элементы (кнопка озвучки, подсказка) при этом не
  переворачиваются зеркально.
- **Backdrop-blur** — при открытии модалок и всплывающих меню фон позади
  размывается, а не просто затемняется, что мягче фокусирует внимание.
- **Экран «Учить»** оформлен так, чтобы ничего не отвлекало от самой
  карточки: печати «Знал» / «Не знал» — крупные, с однозначным цветовым
  кодированием (зелёный/красный), и появляются только когда есть что
  оценивать (после первого переворота).
- Шрифты — системные (не подключаются извне): офлайн-режим PWA не должен
  зависеть от загрузки шрифтов из интернета. По начертанию они близки к
  Inter/Roboto на большинстве устройств (на iPhone это San Francisco).

## Качество и доступность

Приложение прошло аудит и доработано по его результатам:

- **Клавиатура и скринридеры**: карточка в «Учить» — полноценный элемент
  управления (`role="button"`, фокусируется по Tab, переворачивается по
  Enter/Space, `aria-label` объявляет текущую сторону). Во всех модалках —
  `role="dialog"`, `Escape` закрывает, `Tab`/`Shift+Tab` не даёт фокусу уйти
  за пределы модалки, после закрытия фокус возвращается туда, откуда открыли.
- **Масштабирование не блокируется** — можно увеличивать текст жестом, как
  в любом нормальном сайте.
- **Хранилище недоступно** (например, приватный режим Safari) — вместо
  тихого зависания показывается понятный экран с объяснением и кнопкой
  «Попробовать снова».
- **Отмена удаления**: после удаления карточки (в «Карточки», «Учить» или
  «Слушать») тост с кнопкой «Отменить» — 6.5 секунд на то, чтобы передумать.
- **CSV** — полноценный разбор формата: поля в кавычках могут содержать
  переносы строк и запятые, а заголовок таблицы распознаётся только если
  совпадают обе колонки (не спутает настоящую пару слово/перевод с
  заголовком). Экспорт — с BOM и переносами строк, чтобы кириллица корректно
  открывалась в Excel.
- Дебаунс кнопки подтверждения (не отправит действие дважды при двойном
  клике), стабильные цвета колод (хранятся в колоде, не «плавают» при
  удалении других колод), тулбар «Карточки» сгруппирован (частые действия —
  крупными кнопками, редкие — в «⋯»), 5 вкладок вместо 6 (статистика и
  настройки объединены в «Ещё»).

## Режим «Слушать»

Вкладка «🔊 Слушать» читает вслух все карточки активной колоды по очереди —
слово на изучаемом языке, пауза, перевод, пауза, следующая карточка — так
можно слушать колоду как подкаст, не держа телефон в руках. Работает через
встроенный в iOS синтезатор речи (Web Speech API) — так же полностью офлайн,
без интернета.

Управление: пауза/воспроизведение, вперёд/назад по карточкам, переключатели
«случайный порядок» и «повторять по кругу» (бесконечный луп для фоновой
прокрутки).

**Важно про язык произношения**: у каждой колоды теперь есть язык слов и
язык перевода (задаются при создании колоды или потом через ✏️ на строке
колоды в списке колод) — иначе, например, польское слово прочиталось бы с
русским произношением. По умолчанию для новых колод — польский → русский,
это легко поменять на нужную пару (английский, немецкий, французский,
испанский, итальянский, украинский, русский).

В сессии прослушивания рядом со счётчиком тоже есть ✏️ и 🗑 — можно
отредактировать или удалить текущую карточку прямо во время прослушивания,
не останавливая сессию. Пока открыто окно редактирования/подтверждения,
озвучка ставится на паузу и возобновляется автоматически, если играла до этого.

## Язык интерфейса

Приложение полностью переведено на три языка — русский, English и polski.
Переключить можно на вкладке «Ещё» → «Язык приложения» (или "App
language" / "Język aplikacji" — в зависимости от того, какой язык сейчас
выбран). Интерфейс обновляется сразу, без перезагрузки страницы. Названия
своих колод и карточек (то, что ты сам ввёл) при этом не переводятся —
меняются только подписи кнопок, заголовки экранов, подсказки и уведомления.

## Прямо во время «Учить»

Карточку можно переворачивать сколько угодно раз подряд — тап снова показывает
слово, ещё один тап снова показывает ответ, и так далее. Удобно, если после
ответа хочется ещё раз взглянуть на слово. Кнопки «Знал» / «Не знал» появляются
после первого переворота и остаются доступны, даже если потом вернуться
к лицевой стороне — отвечать можно в любой момент, не обязательно с открытым
ответом на экране.

На карточке есть ещё две мелкие кнопки:

- **🔊** (правый верхний угол карточки) — озвучивает вслух ту сторону
  карточки, что сейчас видна (слово до переворота, перевод после), голосом
  нужного языка. Не переворачивает карточку.
- **🗑** (рядом со строкой «осталось выучить: N») — удаляет текущую карточку
  из колоды навсегда, с подтверждением. Полезно, если попалось опечатанное
  или ненужное слово прямо во время повторения — не нужно идти на вкладку
  «Карточки» отдельно.

## Как считается интервал повторения

Внутри одной сессии карточка, на которую ответили «Не знал», возвращается
в конец очереди и показывается снова — так что сессия заканчивается только
когда все карточки отвечены верно хотя бы раз. Но на долгосрочный интервал
повторения (когда карточка появится в следующий раз, через день / 3 дня /
неделю и т.д.) влияет только **первая попытка** по каждой карточке за
сессию:

- Угадали с первого раза → уровень карточки растёт, следующий показ
  откладывается дальше.
- Ошиблись на первой попытке (даже если через пару кругов всё-таки
  вспомнили) → уровень сбрасывается на 1 (частый повтор, но не самое начало) — итоговый
  правильный ответ в рамках той же сессии на это уже не влияет.

Это отличает по-настоящему выученные с первого раза слова от тех, что
дались с трудом, даже если в конце сессии оба варианта помечены «знал».

Если хочешь пройти всю колоду заново (например, после долгого перерыва) —
на вкладке «Карточки» кнопка «Сбросить уровни» позволяет вручную сбросить
уровень всех карточек колоды до 1 или до 0 и сразу сделать их доступными
к повторению. Карточки при этом не удаляются — сбрасывается только прогресс.

## Редактирование карточек

В списке карточек рядом с ✕ (удалить) есть ✏️ — открывает то же поле
«слово / перевод», что и при добавлении, только уже заполненное текущими
значениями. Если исправленная пара совпадёт с какой-то другой карточкой
в той же колоде, сохранение отклонится как дубль (карточка не поменяется).

Так же ✏️ появляется и в режиме «Учить» — рядом с 🗑, но только в момент,
когда виден ответ (после переворота карточки). Правка применяется сразу,
без перезапуска сессии.

## Экспорт колоды

На вкладке «Карточки» кнопка «Экспорт» скачивает все карточки активной
колоды файлом `.csv` или `.json` (на выбор) — ровно в том же формате, что
понимает «Импорт файла», так что файл можно тут же загрузить обратно (себе
или на другое устройство) без потерь. Имя файла берётся из названия колоды.

## Объединение колод

На экране «Колоды» кнопка «🔗 Объединить колоды» открывает выбор двух колод:
всё содержимое первой переедет во вторую (дубли — одинаковые пары
слово+перевод — пропускаются, как и везде в приложении), а первая колода
удалится. Работает только для колод с одинаковой языковой парой (слово и
перевод) — иначе объединение заблокировано, чтобы не перемешать разные
языки в одной колоде.

## Статистика и настройки

Вкладка «⋯ Ещё» (последняя в меню снизу) объединяет статистику активной
колоды и настройки приложения — чтобы не плодить лишние вкладки в нижнем
меню:

- **Язык приложения** — русский / English / Polski, переключается мгновенно
- **Подтверждать удаление карточки** — если выключить, кнопка 🗑 в режиме
  «Учить»/«Слушать» удаляет карточку сразу, без всплывающего вопроса
  «Уверен?». (Подтверждение при удалении из списка «Карточки» и при
  очистке/удалении колод целиком остаётся всегда — это переключает только
  быстрое удаление прямо во время повторения/прослушивания. В любом случае
  после удаления есть 6.5 секунд на отмену через тост.)
- **Кнопка удаления карточки в «Учить»** — сверху рядом со счётчиком
  «осталось выучить» (по умолчанию) или снизу, под кнопками «Знал» / «Не
  знал».

Настройки хранятся на устройстве и не сбрасываются при перезапуске
приложения.

## Почему нельзя просто "включить .py на айфоне"

iOS не даёт запускать сторонние исполняемые файлы (в т.ч. Python) в обход
App Store — это ограничение самой платформы, не наше. Реальные варианты были:
Pythonista/Pyto (покупка приложения-интерпретатора), нативная сборка через
BeeWare/Kivy (нужен Mac + Xcode + Apple ID), или веб-приложение (PWA). Ты
выбрал(а) PWA — оно не на Python (HTML/CSS/JS), зато не требует ничего,
кроме однократной публикации файлов и Safari.

## Важно: нужен один раз статический хостинг

PWA нельзя "просто открыть" двойным щелчком и получить офлайн-режим и кнопку
"На экран Домой" — Safari требует, чтобы страница была отдана по `https://`
(или `http://localhost`), иначе Service Worker (то, что обеспечивает офлайн-
работу) не активируется. Это **не сервер в смысле бота** — файлы статические,
ничего не считается на бэкенде, но разместить их где-то по https нужно.

### Шаг 1. Выложить файлы на GitHub Pages

1. Создай новый репозиторий на [github.com](https://github.com) (можно приватный).
2. Загрузи в него все файлы из этой папки (`index.html`, `style.css`, `db.js`,
   `app.js`, `manifest.webmanifest`, `service-worker.js`, папку `icons/`) —
   через веб-интерфейс (Add file → Upload files) или `git push`.
3. В репозитории: **Settings → Pages → Source: Deploy from branch → main /
   (root)** → Save.
4. Через минуту-две GitHub покажет ссылку вида
   `https://<твой-логин>.github.io/<репозиторий>/` — открой её в Safari
   **на iPhone**, чтобы проверить, что всё загрузилось.

(Вместо GitHub Pages подойдёт любой другой статический хостинг — Netlify,
Cloudflare Pages, Vercel — процесс аналогичный: загрузить папку, получить
https-ссылку.)

### Шаг 2. Установить на домашний экран

1. Открой полученную ссылку в **Safari** на iPhone (обязательно Safari, не
   Chrome — только Safari умеет ставить PWA на домашний экран на iOS).
2. Нажми кнопку "Поделиться" (квадрат со стрелкой вверх) внизу экрана.
3. Выбери **"На экран «Домой»"**.
4. Нажми "Добавить".

Готово — на экране появится иконка "Картотека". Она открывается как обычное
приложение (без адресной строки Safari) и с этого момента работает офлайн:
можно выключить Wi-Fi/интернет совсем, приложение продолжит работать, а все
карточки и прогресс сохраняются на телефоне.

### Про обновления

Если ты попросишь что-то доработать и я пришлю новые файлы — обнови их в том
же репозитории (замени файлы, GitHub Pages подхватит автоматически). Дальше
приложение само скачивает новую версию в фоне и как только она готова —
показывает тост «Доступно обновление приложения» с кнопкой «Обновить»:
нажимаешь — применяется сразу, без явного нажатия обновление просто ждёт
следующего полного перезапуска приложения (никаких файлов или данных это не
портит, колоды и прогресс всегда остаются на месте — они отдельно, в
IndexedDB).

**Важное исключение:** переход именно на эту версию (где появился тост) сам
по себе через тост не покажется — старая версия ещё не знает о нём. Один
раз обнови вручную как раньше (полностью закрой приложение — смахни из
списка недавних — и открой заново, при необходимости дважды). Начиная со
следующего обновления тост будет работать сам.

## Структура файлов

```
index.html               — разметка всех экранов
style.css                 — оформление (тёмная тема, латунный акцент)
i18n.js                   — переводы интерфейса (ru/en/pl) и функция t()
db.js                     — вся работа с IndexedDB (колоды, карточки, SRS)
speech.js                 — озвучка карточек через Web Speech API
app.js                    — логика интерфейса, импорт CSV/JSON, сессии обучения и прослушивания
manifest.webmanifest      — метаданные для установки на домашний экран
service-worker.js         — кэш для офлайн-работы + флоу обновлений с согласием
tests/logic.test.mjs      — юнит-тесты (SM-2, CSV-парсер, очередь "Слушать")
icons/                    — иконки приложения разных размеров
```

## Юнит-тесты

Логика, не завязанная на браузер (SM-2 lite, разбор CSV, очередь
воспроизведения в «Слушать»), вынесена в чистые функции и покрыта тестами
без сторонних фреймворков — только встроенный `node:assert`:

```bash
node tests/logic.test.mjs
```

Два теста (`updateCardProgress` через настоящую БД, `createDeck` с явным
цветом) дополнительно используют `fake-indexeddb` — без него они просто
аккуратно пропустятся с предупреждением, остальные 19 всё равно отработают.
Чтобы включить и их:

```bash
cd tests && npm install fake-indexeddb --no-save && node logic.test.mjs
```

## Импорт существующих карточек

Открой приложение → вкладка "Карточки" → "Импорт файла" → выбери `.csv` или
`.json`. Форматы те же, что понимал телеграм-бот — можно использовать файлы
`polish_b1.csv`, `english_b1_c2_all.json` и другие, которые уже были
сгенерированы ранее в этом разговоре.
